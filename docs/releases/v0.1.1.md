首个 GitHub Release，整合本轮合入的功能修复、配置保护和自动合并流程。适用于 macOS 13 及以上，安装包同时支持 Apple 芯片和 Intel。

## 配置与权限提醒

- 手改 `config.json` 后，空闲时也会自动生效，支持编辑器的原子保存、原地写入，以及配置目录的删除和重建。
- 菜单读取最新配置，只改选中的项目；保留未知奶蛙名、时段和字段。JSON 临时写坏时保留上次有效安排，并拒绝覆盖损坏的文件；保留配置符号链接和文件权限。#45
- 权限提醒最多显示 60 秒，之后恢复干活，保留工具的原始计时。Claude 不提供批准完成事件，因此即使尚未批准，提醒也会到时停止；不会替用户批准操作。表单和回复等待不受此上限影响。
- 演示改为真实的工具完成事件，不再伪造批准时的工具开始事件。#45

## Claude Code 会话

- 工具失败、Esc 中断和 API 错误能清理相应状态；过期会话由定时器主动清理。#20
- 并行工具分别记账，完成一个工具不会误清另一个工具的等待；无 ID 权限通知按唯一候选归属，无法判断时保留为未分配请求。长任务不会因半小时静默丢失计时，未完成工具最多保留 6 小时。#42
- 被其他 hook 拦下的 Stop 与后续执行算同一轮，一轮最多反应一次。#32
- 项目名沿用会话最初的目录，不随中途切换目录改变。#31

## 窗口与播放

- 分别记录锁屏、屏幕睡眠和用户切换状态，避免仍锁屏时唤醒屏幕就恢复循环。#21
- 调整大小时把奶蛙留在屏幕可见区域；显示器变化时，气泡跟随奶蛙重新定位。#22
- 每帧更新鼠标穿透，解决指针不动、动画形状变化时的点击遮挡。#30
- 视频缺失或损坏时停止取帧并退出当前反应；跳过损坏的悬停选择，尝试其他可播放视频，避免卡住或反复重试。#28
- 停止、重播或取消跳转后，过期的异步回调不能重新启动旧播放。#35

## 下载与升级

下载 `Naiwa-v0.1.1-macos-universal.zip`，解压后将 `Naiwa.app` 放入 `~/Applications`。更新已有安装时，先通过奶蛙右键菜单退出，再替换 App 并重新打开。

旧版用户更新后重新运行一次 `naiwa hooks install`，补上工具失败和 API 错误事件。没有配置命令行链接时，可以运行：

```bash
~/Applications/Naiwa.app/Contents/MacOS/naiwa hooks install
```

下载包沿用 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证，首次打开可能被 macOS 拦截。也可以继续使用 README 中的源码安装方式。
